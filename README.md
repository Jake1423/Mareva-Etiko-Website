# Mareva-Etiko-Website

Mareva Etiko website to test a company's confidence index for AI readiness.

## Project layout

- `index.html` - Netlify entry point and page markup.
- `frontend/src/styles.css` - Styles extracted from the original inline stylesheet.
- `frontend/src/app.js` - Browser JavaScript extracted from the original inline script.
- `QA_TEST_CASES.md` - Sprint scoring and validation test cases.
- `Mareva_Etiko_Methodology_Note.pdf` - Linked methodology note used by the website footer.
